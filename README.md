# Trabalho Prog II
## Resumo
O que precisamos ter:
 - 3 structs (Pessoa, Ocorrencia, Evidencia) armazenadas em vetor (mínimo 10.000 pessoas, 5.000 ocorrências, 20.000 evidências)
 - Cadastro com validação (IDs únicos, campos obrigatórios, idade/gravidade válidas)
 - 2 algoritmos de ordenação diferentes
 - Busca sequencial e busca binária
 - 2 funcionalidades recursivas: uma obrigatória (calcular relevância total de evidências de uma ocorrência, considerando evidências relacionadas) e uma segunda definida pelo grupo
 - Relatório de desempenho gerado pelo próprio programa (comparações, trocas, tempo) testando com 1.000 / 5.000 / 10.000 / 50.000 registros
 - Menu principal integrando tudo, código modularizado
 - Tratamento de erros (ID duplicado, busca sem resultado, ocorrência sem evidências, etc.)
 - Relatório escrito + apresentação de 15-20 min, com defesa individual (cada um precisa saber explicar qualquer parte do código)
